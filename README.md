# منصة إغلاق تذاكر الزائر السري

أداة بسيطة تعمل في المتصفح: يكتب المستخدم بيانات التذكرة والملاحظات ويرفق صور الإثبات، فيُنشأ ملف
PowerPoint جاهز من القالب الرسمي بالهوية البصرية الجديدة.

- **بدون تسجيل دخول وبدون حسابات أو رموز** — أي شخص يفتح الرابط ويبدأ فورًا.
- **بدون خادم** — لا تُرسل أي بيانات أو صور إلى أي جهة؛ كل شيء يتم داخل متصفح المستخدم.
- التقارير غير المنتهية تُحفظ تلقائيًا في متصفح الجهاز ليتمكن المستخدم من متابعتها لاحقًا.

## التشغيل

```bash
npm install
npm run dev        # للتطوير على http://localhost:5173
npm run build      # نسخة النشر داخل مجلد dist
npm run preview    # معاينة نسخة النشر
npm run test:pptx -- out.pptx   # اختبار التوليد: تذكرة + 3 ملاحظات = 4 شرائح
```

## النشر

الناتج في `dist` ملفات ثابتة (HTML/JS/CSS) ترفع على أي استضافة: GitHub Pages أو Netlify أو Vercel أو أي
مساحة ويب. لا حاجة لقاعدة بيانات ولا متغيرات بيئة ولا أي إعداد.

التطبيق يستخدم `HashRouter` و`base: './'`، لذلك يعمل من أي مسار فرعي دون إعداد إضافي على الخادم.

## طريقة الاستخدام

1. **بيانات التذكرة**: اسم المنشأة، رقم التذكرة، رقم الزيارة، عنوان التذكرة، التاريخ.
2. **الملاحظات والصور**: لكل ملاحظة نصها والإجراء التصحيحي وصور الإثبات (JPG · JPEG · PNG · WEBP).
3. **المعاينة**: مراجعة ما سيظهر داخل الشرائح.
4. **التحميل**: يُنشأ الملف وينزّل تلقائيًا باسم `[اسم المنشأة] – [عنوان التذكرة].pptx`.

عدد الشرائح = شريحة بيانات التقرير + شريحة لكل ملاحظة.

## ملف PowerPoint

- القالب الرسمي في `public/templates/ticket-closure-template.pptx`؛ لتحديثه استبدل الملف بنفس الاسم
  مع المحافظة على بنية الشرائح (شريحة التعليمات، شريحة البيانات، شريحة الملاحظة).
- تُحذف شريحة التعليمات، وتُعبأ شريحة البيانات باللون الأسود، وتُنسخ شريحة الملاحظة لكل ملاحظة.
- النصوص الطويلة يُصغَّر خطها تلقائيًا لتبقى داخل حدود الشريحة.
- الصور تُرتب في شبكة داخل منطقة الإثبات دون تشويه النسب.

## بنية المشروع

```
src/
  pages/            الرئيسية (التقارير المحفوظة) ومحرر التقرير
  components/       نموذج البيانات، بطاقة الملاحظة، رفع الصور، المعاينة
  services/
    store.ts        حفظ التقارير والصور داخل المتصفح (IndexedDB)
    fileService.ts  توليد الملف وتنزيله
    powerpointGenerator/   توليد PowerPoint من القالب (JSZip + XML)
  utils/            التواريخ، اسم الملف، معالجة الصور، التحقق من البيانات
public/
  templates/        القالب الرسمي
  fonts/ brand/     خط A Jannat وشعارات الزائر السري
```

## ملاحظات

- التقارير والصور محفوظة في متصفح الجهاز فقط: لا تظهر على جهاز آخر، وتُفقد عند مسح بيانات المتصفح،
  لذلك يُنزَّل ملف PowerPoint فور إنشائه.
- الصور تُصغَّر تلقائيًا (بحد أقصى 1920 بكسل) وتُحوَّل WEBP إلى JPEG لضمان توافقها مع PowerPoint.
